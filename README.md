
# Oravel Lifestyle

Oravel Lifestyle is a full-stack e-commerce platform designed to provide a modern, responsive, and user-friendly online shopping experience.

## 🌐 Live Website

[Visit Oravel Lifestyle](https://oravel-lifestyle-client.vercel.app)

## ✨ Features

- Modern and responsive user interface
- Product browsing and category filtering
- Shopping cart management
- Customer registration and login
- Email OTP verification
- Password recovery
- Cash on Delivery (COD)
- Order history and tracking
- Admin dashboard
- Contact and newsletter management
- MongoDB Atlas integration
- Separate frontend and backend architecture

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| JavaScript | Frontend Development |
| CSS | UI Design and Styling |
| Node.js | Backend Development |
| REST API | Client-Server Communication |
| MongoDB Atlas | Cloud Database |
| Nodemailer | Email Verification |
| Vercel | Cloud Hosting |
| GitHub | Version Control |

## 🔐 Security

- Environment-based credential management
- Server-side authentication
- Email OTP verification
- Protected admin API routes
- CORS configuration
- Server-side order validation

## 🚀 Deployment

The frontend and backend are independently deployed on Vercel and connected to MongoDB Atlas for cloud-based data storage.
